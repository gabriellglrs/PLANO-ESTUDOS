Guia Completo · Do Zero ao Aprovado
Estudo Reverso por Questão

O método que permite aprender do absoluto zero usando somente questões de concurso como ferramenta principal.

🧠 O Fundamento — Por que estudar por questões funciona do zero?
💡
A grande virada de mentalidade
Resolva questões desde o dia 1 e aprenda a teoria conforme a necessidade — não o contrário.
✗
Método Tradicional (lento)
① Ler capítulo inteiro de teoria
② Fazer resumo / fichamento
③ Resolver questões "para testar"
✓
Estudo Reverso (rápido)
① Resolver questão sem saber nada
② Ler o gabarito comentado
③ Registrar erro no caderno
Reiniciar progresso?
O progresso do plano será zerado. O caderno de erros não será afetado.
🗑 Limpar TUDO?
Isso vai apagar TODO o cache e dados na nuvem: progresso, caderno de erros, configurações, progresso do índice.
AÇÃO IRREVERSÍVEL.
Desmarcar todos os tópicos?
Todo o progresso marcado no índice será removido. O caderno de erros e o plano não serão afetados.
Guia Completo
Como usar o Plano de Estudos
🗺 Visão geral
☁ Dados na nuvem (Supabase)
Todos os dados são salvos automaticamente no Supabase. O localStorage é usado como cache offline.
🔍 Diagnóstico
Abra o console do navegador (F12) e execute diagnosticoSupabase() para verificar o status de cada tabela.
⚙ Configurações
📅 Data de início
Define o começo do ciclo. O dia de hoje fica destacado em verde no plano.
⚡ Questões / hora
Iniciante: 10–15 qs/h. Aumente conforme evoluir.
☁ Dados na nuvem
Como funciona
Toda alteração é salva simultaneamente no Supabase (nuvem) e no localStorage (cache local).
💡 Execute o SQL de setup no Supabase antes de usar. Inclua a tabela indice_progress para salvar os checkboxes do índice na nuvem.
📓 Caderno de Erros
⏱ Tempo de Revisão por Dia
Configure quantos minutos de revisão dedicar em cada dia. Este tempo é descontado do estudo novo automaticamente.
🧠 Revisão Espaçada
Intervalos recomendados (Concursos)
+1 dia → Consolidação inicial
+3 dias → Reforço
+7 dias → Fixação semanal
+14 dias → Consolidação quinzenal
+30 dias → Memória de longo prazo
💡 Padrão 1·3·7·14·30 — o mais adotado por concurseiros experientes.
📋 Índice com Checkboxes
Como usar
Na aba Índice TEC, cada tópico e subtópico tem um checkbox. Marque quando terminar as questões daquele assunto. O item ficará riscado indicando que foi concluído.
💡 O progresso é salvo automaticamente no Supabase e no localStorage. Você pode ver sua % de conclusão por matéria e categoria.
SQL necessário no Supabase
Crie a tabela indice_progress com:
CREATE TABLE indice_progress (user_id text PRIMARY KEY, checked_items jsonb, updated_at timestamptz);
